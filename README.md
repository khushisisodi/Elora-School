# 🏫 Elora International School Website

A modern, fully responsive, and feature-rich school web application built with clean HTML5, CSS3, and JavaScript. Designed to deliver an engaging digital experience for prospective students, parents, and faculty members.

---

## 🌟 Features

* **Interactive Hero Slider:** Smooth sliding image animations with manual controls and auto-play functionality.
* **Smooth Scroll Physics:** Integrated with Lenis JS for an ultra-smooth scrolling experience.
* **Dynamic Statistics Counter:** Animated statistical counters showcasing student strength, faculty count, and achievements.
* **Campus Gallery & Facilities:** Showcases smart classrooms, sports complexes, labs, and the library.
* **Interactive Admission Form:** A dedicated, user-friendly student registration form (`form.html`) with validation and responsive grid layout.
* **Fully Responsive:** Optimized seamlessly for mobile phones, tablets, and desktop screens.

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, Grid, Animations, Custom Gradients)
* **Scripting:** JavaScript (DOM Manipulation, Intersection Observer API)
* **Libraries:** Lenis JS (Smooth Scrolling)
